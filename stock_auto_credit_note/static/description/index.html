Overview

When a customer returns goods, your accounts team should not have to manually locate the original invoice and raise a credit note. This free Odoo 19 module closes that gap — the moment a return delivery is validated, a draft credit note is automatically created against every relevant posted invoice.

Partial returns are handled correctly. Only the products and quantities actually returned are credited. Lines for products not included in the return are removed from the credit note, so your accountant sees a clean, accurate document ready to review and post.

⚡

Zero manual steps. Validate the return delivery → draft credit note appears automatically, scoped to exact returned quantities. Only triggers when a posted invoice exists — safe and predictable.

Key Features

Automatic Credit Note

Draft credit note created on return delivery validation — no buttons, no wizards.

Partial Return Support

Returns 3 of 10 units? Only 3 units credited. Line-by-line matching, not full reversal.

Invoice Gate Check

Only fires when a posted out_invoice exists. Draft invoices are safely ignored.

Draft for Review

Credit note stays in draft — accountant verifies before posting to the ledger.

Chatter Cross-Links

Both the return delivery and credit note log messages linking to each other.

Multi-Invoice Aware

Quantities distributed across batch invoices — no double-crediting.

Sale Order Linked

Works via return_id → sale_id → invoice_ids — no custom fields needed.

Invoice Stat Button

Smart button on original delivery showing linked posted invoice count.
